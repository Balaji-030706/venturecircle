# VentureCircle 

VentureCircle is a web-based platform that connects shopkeepers within the same business category.

## Features
- Shopkeeper login
- Add products
- View products by category
- View other shopkeepers
- Activity tracking

## Tech Used
- HTML
- CSS
- JavaScript
- LocalStorage

## How it Works
- Users register/login
- Products are stored locally
- Dashboard displays relevant data

## Future Scope
- Firebase integration
- Real-time updates
- GPS tracking
